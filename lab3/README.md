# Лабораторная работа №3 — Текстурирование

Вариант 11. В сцене два икосаэдра на фоне луга с облаками.

## Запуск на Windows

Понадобятся Visual Studio 2022 с компонентом «Разработка классических приложений на C++», CMake 3.22+ и Vulkan SDK с `glslc.exe`. GLFW, Dear ImGui, vk-bootstrap, VMA и stb_image входят в проект. Для сборки самого проекта скачивать зависимости из GitHub не требуется.

Распакуй архив. В Visual Studio выбери **File → Open → Folder**, открой папку `CG-lab3`, выбери конфигурацию `msvc-debug` и цель `vulkan-starter-app.exe`, затем запусти через **Ctrl+F5**.

Те же действия из PowerShell в папке `CG-lab3`:

```powershell
cmake --preset msvc-debug
cmake --build build-debug --config Debug
.\build-debug\bin\Debug\vulkan-starter-app.exe
```

При сборке CMake компилирует GLSL и размещает папки `shaders` и `textures` рядом с программой. Программа ищет эти папки относительно расположения exe.

## Что показать при запуске

1. В меню **Textures → Left texture** и **Right texture** выбери картинку для каждой фигуры. Можно поставить одну и ту же текстуру на обе фигуры для сравнения.
2. Выключи **Animated sampling (right)**, чтобы сравнить обычное наложение и анимированный эффект на одной и той же текстуре.
3. Останови вращение фигур в **Objects and material → Pause animation**. Эффект продолжит двигаться даже на неподвижной грани, если галочка включена.
4. Измени интенсивность света в **Directional and ambient light**, чтобы показать, как освещение влияет на текстуру альбедо.

## Где искать реализацию

| Требование | Реализация |
| --- | --- |
| UV-координаты | В `application.cpp` каждая из 20 граней получает три UV. Вершинный шейдер передаёт их фрагментному, а GPU интерполирует их по грани. |
| Изображения из файловой системы | `gpu_resources.cpp` читает файлы, декодирует их через stb_image и копирует RGBA в Vulkan-изображения через staging-буфер. Сэмплер использует линейную фильтрацию и clamp-to-edge. |
| Буферы геометрии в памяти GPU | `uploadMesh` записывает вершины и индексы в staging-буфер и переносит их в device-local буферы командами `vkCmdCopyBuffer`. |
| Один динамический UBO для моделей | `set=1, binding=0` имеет тип `VK_DESCRIPTOR_TYPE_UNIFORM_BUFFER_DYNAMIC`. В буфере две структуры `ModelUniform`. Левая фигура читает запись со смещением 0, правая — со смещением `modelStride`. Vulkan получает эти смещения через `vkCmdBindDescriptorSets`. |
| Выбор текстуры для каждого икосаэдра | У каждой текстуры свой набор дескрипторов. Все наборы ссылаются на общий динамический UBO и содержат собственную пару image view + sampler в `set=1, binding=1`. |
| Нетривиальное сэмплирование | `sampleAlbedo()` в `icosahedron.frag` дважды читает ту же текстуру по разным UV, модулирует цвета и смешивает их. Флаг эффекта и время передаются через push-константы. Полученный цвет идёт в расчёт освещения как альбедо. |

Лекция 5 объясняет UV и сэмплирование, 5.2 — загрузку и привязку текстуры в Vulkan, 6 — динамический UBO, копирование геометрии и push-константы.

## Как подставить свою картинку

Замени нужный JPEG в папке `textures` и пересобери проект. Программа читает `cat-heart.jpg`, `cat-action.jpg` и `jungkook.jpg`. Изображение повторяется на каждой из 20 треугольных граней.

Фон загружается из `textures/meadow.jpg` и рисуется первым, одним треугольником на весь экран. При изменении размера окна фотография обрезается по краям с сохранением пропорций.
